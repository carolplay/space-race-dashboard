# Alpha 1.9.0 — 星座空间实验室

2026-10-11，用户确认推进“看板之外的视角”，将前几轮星座内容和视觉展示加入项目。此前讨论中的空间视图未实施限制在本轮被明确解除；五大数字栏目仍保留，另增独立入口 `/constellations`。

## 产品取舍

- 四种视角：轨道空间、部署历程、功能网络、资料与方法。空间页以星座为入口，联动物理库存、GP 覆盖、对象证据、高度/倾角分组和 RAAN 分布；不是全卫星及碎片地图。
- 五组真实输入：Starlink、OneWeb、Amazon LEO、国网、千帆。按需加载保存在本项目的轨道快照，页面不直接请求上游。默认只看一个星座，可叠加五组。
- 拖动与键盘旋转、缩放、短时播放、时间滑块、对象名称/NORAD 搜索及点选轨迹；支持手机和中英切换。真实高度比例默认，另设明确标注的 3× 高度示意。
- 既有部署增长、阶段目标和官方功能关系作为独立视角复用，不将动画推算用于更新历史库存或制造新的服务依赖。

## 真实数据与计算

[CelesTrak GP 查询规范](https://celestrak.org/NORAD/documentation/gp-data-formats.php)明确 OMM-compatible JSON 与 SGP4 均值要素；JSON 支持六位及更大目录编号。本轮取官方列表的 starlink / oneweb / kuiper / hulianwang / qianfan 分组，分别保留 URL、完整响应 SHA-256、检索日期和逐对象要素历元。

快照获取于 **2026-10-11 07:52:07 UTC**，不是上游统一更新时间。共 12,624 个 GP 对象：11,102 / 651 / 391 / 224 / 256。各对象要素日期不同，初始快照时有两条超过七天，默认不绘制。GCAT 库存仍截至 10 月 9 日，不为迎合 GP 目录自动修改数量或计算跨日差值。

采用 [satellite.js](https://github.com/shashwatak/satellite-js) **6.0.2 / MIT** 的 SGP4，从 TEME 位置转为地固坐标，以 Canvas 正交投影显示。选择纯 JavaScript 版本以避免当前构建器处理不需要的多线程 WASM 时失败；不修改上游程序或构建器来伪造通过。

- 播放窗口限定在保存快照时间的 ±6 小时，1 分钟/秒。不是多年轨道重放或持续遥测。
- 所选对象白线为未来一周回的地固推算轨迹，不是星间链路或轨道面的自动识别结果。
- 不提供未知机动、真实网络路由、运营状态、业务容量、碰撞警报或未经验证的地面覆盖。
- 地球采用参考球面，没有真实地形/地理底图；背景星点只作装饰，不作为目录对象。
- 高度分组用平均运动推导的半长轴高度（25 km / 1°）；RAAN 按各自历元分成 10° 桶，不等于已识别的轨道面数，也不随播放时间更新。

## 更新与来源边界

新增 `data:update:constellation-space` 并接入既有在轨更新脚本。遵守 [CelesTrak 使用政策](https://celestrak.org/usage-policy.php)：共享快照缓存，至少两小时才允许再取，每组只取一次，遇非 200 立即停止，无重试循环。五组均获取及校验成功后才改动上次发布文件。后续每日任务按原流程自然刷新。

来源健康报告新增 GP 输入：上游未提供单一更新时间时保留 null，以逐组最新历元做陈旧复核，不把获取日期冒充上游更新。具体旧对象仍在空间页计数并排除。

参考目录复用已有 Starlink Mission Control / Orbital Radar 记录；借鉴星座级下钻和观测/模拟分离，不复制界面，也不新增 Orbital Radar 的系统性提取。其它参考模拟项目（Hypatia / SaVi）仍作研究参考，未引入假设网络到生产状态。

## 验收

31 项测试涵盖原看板、GP 数值/历元/六位编号、去重、分组守恒、传播与坐标旋转、缺失拒收及新路由 SSR。浏览器检查覆盖拖动、方向键、对象选择、时间播放、五组加载、四视角、中英刷新保持、390px 手机布局，并验证画布真实绘制出轨道点，无浏览器脚本错误。运行时依赖审计无已知漏洞；开发依赖已有漏洞未在本轮强制升级。仓库原有 Cloudflare 环境类型缺口仍单独记录，不声称完整 TypeScript 检查通过。

发布沿用既有公开站点，目标 1.9.0；发布编号与远端复核结果另存更新记录。后续可讨论真实壳层/轨道面识别算法、设计槽位的独立对照层、几何可见性与地面站（各需单独数据和明确假设），不自动承诺真实通信拓扑。
